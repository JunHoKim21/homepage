2. 2GB RAM 저가 서버 생존을 위한 수학적 JVM 메모리 공식

JAVA_TOOL_OPTIONS="-Xms256m -Xmx420m -XX:MaxMetaspaceSize=128m -XX:ReservedCodeCacheSize=64m -XX:MaxDirectMemorySize=64m -XX:+UseSerialGC -XX:+ExitOnOutOfMemoryError"
➔ Heap(420MB) + Metaspace(128MB) + CodeCache(64MB) + Direct(64MB) + Native/Threads(~50MB) = 726MB ≤ 768MB 엄격 보장

4. 크몽 수주 특화 4대 핵심 기능 & 하이브리드 예약 옵션 명세

[핵심 1] 무코드 SEO·브랜딩 관리 + 사장님 실수 잠금(is_system) + 0.1초 즉시 갱신

관리자에서 제목, 카톡 공유 썸네일(seo_og_image), 대표 색상(brand_primary_color) 수정 시 AFTER_COMMIT 이벤트가 로컬 Caffeine 캐시를 비우고 Next.js /api/revalidate(X-Revalidate-Secret 검증)를 호출해 0.1초 만에 반영합니다. is_system = true 항목은 삭제를 원천 차단합니다.

[핵심 2] 업종별 동적 상담 문의(custom_fields JSONB) + 스팸 봇 3중 무료 방어막

Honeypot 숨김 필드 + Caffeine IP Rate Limit(1분 3회) + server.forward-headers-strategy: native(8080 내부 격리)로 해외 스팸 봇의 알림톡 요금 폭탄을 100% 차단합니다.

[핵심 3] 하이브리드 예약 시스템 — 2단계 스위치 (채널 모드 × 정원 옵션)

  • 제1스위치 (reservation_mode): OFF | NAVER (네이버 스마트플레이스 직결) | INTERNAL (자체 예약) | BOTH (동시 노출)
  • 제2스위치 (reservation_capacity_mode): SINGLE (1:1 단독 예약 — 법무·세무·스튜디오·1인샵, 정원 1명 고정) ↔ MULTI (시간대별 N명 정원제 — 병원·학원·원데이클래스, 슬롯별 max_capacity 설정 및 잔여석 표시)
  • 동시성 방어: reservation_slots 행 잠금(SELECT ... FOR UPDATE)과 CHECK (reserved_count <= max_capacity)로 초과 예약을 완벽 차단합니다.

[핵심 4] 스마트폰 사진 WebP 자동 다이어트 (Pool=1, Q=50) & 공개/비공개 폴더 이원화

전용 플랫폼 스레드 1개 + ArrayBlockingQueue(50)에서 순차 변환하여 피크 힙을 100MB 이하로 통제합니다. 공개 이미지(/uploads/public)는 Caddy가 직접 서빙하고, 고객 문의 첨부파일(/uploads/private)은 관리자 인가 후 Spring Boot 스트리밍으로만 다운로드합니다.
